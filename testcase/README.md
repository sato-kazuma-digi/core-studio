# QA Core Studio

ISO/IEC/IEEE 29119 および JSTQB 規格に完全準拠した、Webベースの統合テスト仕様書・計画書管理プラットフォーム。

## 主な機能
- **マルチテスト計画管理**: システム・プロジェクトごとのテスト計画書を作成・管理・個別出力
- **ISO 29119 ガバナンス**: 計画書（In/Out of Scope, Entry/Exit Criteria）、仕様書、欠陥トラッキングの完全統合
- **リアルタイム品質メトリクス**: テスト消化率、Pass率、欠陥除去効率 (DRE)、欠陥密度の自動算出
- **テスト設計技法サポート**: 境界値分析、デシジョンテーブル、状態遷移テストのワンクリックテンプレート挿入
- **曖昧ワード自動検出**: 「正常」「速やかに」などの主観的表現を検知し警告
- **データエクスポート/インポート**: 個別計画パッケージ（JSON）およびテストケース（CSV）の出力

## 動作環境
ビルド不要。ブラウザ（Chrome, Edge, Safari）で `index.html` を開くだけで動作します。
